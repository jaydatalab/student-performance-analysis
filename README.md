# 🎓 Student Performance Analysis Using Python & NumPy

## 📌 Project Overview
This is my first Data Analytics portfolio project. It analyzes student marks using Python and NumPy to understand student performance and identify pass and fail statistics.

## 🎯 Project Objectives
- Analyze student marks.
- Find the highest and lowest total marks.
- Count the number of students who passed and failed.
- Calculate the overall pass percentage.

## 🛠️ Tools & Technologies
- Python
- NumPy
- Visual Studio Code

## 📊 Key Insights
- **Total Students:** 8
- **Highest Total Marks:** 265
- **Lowest Total Marks:** 167
- **Students Passed:** 4
- **Students Failed:** 4
- **Pass Percentage:** 50%

## 💡 What I Learned
- Working with NumPy arrays.
- Performing calculations on student marks.
- Analyzing data using maximum and minimum values.
- Filtering data based on conditions.
- Calculating pass and fail statistics.
